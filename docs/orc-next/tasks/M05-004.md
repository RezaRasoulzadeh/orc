# M05-004 — Add read-only Controller Plan review judgment

**Status:** Done
**Milestone:** M05 — Planning and Lead unification

## Objective

Move Plan review judgment from the legacy Lead model path into the local Controller as a bounded, read-only capability without changing canonical Plan review persistence, status transitions, revision execution, approval, or application.

## Result

Implemented bounded `ControllerPlanReviewRequest`, `ControllerPlanReviewState`, typed three-way `ControllerPlanReviewDecision`, bounded `ControllerPlanReviewResult`, strict JSON-schema parsing, and `OrcApp::review_controller_plan`.

Current-valid Plan checks occur deterministically before inference. The Controller review path is read-only: it creates no Lead run/decision, `PlanReview`, Plan status change, approval, revision, task, workflow transition, or worker mutation. Existing legacy Lead Plan review remains unchanged.
