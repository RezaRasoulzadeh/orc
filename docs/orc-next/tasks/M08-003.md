# M08-003 — Add explicit typed curation for Controller recovery recommendations

**Status:** Done
**Milestone:** M08 — Experience dataset

## Objective

Add the next capability-local curation adapter for one already-produced Controller recovery interaction, projecting the existing typed recovery inference input and existing canonical recovery recommendation into one M08-001 experience example under explicit trusted verification metadata.

## Result

Completed in implementation commit `947d2d8e9cf201e82daaa62474be74d26df7ef4f`.

The implementation adds fixed capability `controller.recovery_recommendation`, `ControllerExperienceRecoveryRecommendationRequest`, `ControllerExperienceRecoveryRecommendationError`, and `OrcApp::create_controller_recovery_experience_example(...)`.

It preserves the exact validated `RecoveryInferenceInput` as dataset input and the exact validated accepted `RecoveryRecommendation` as dataset output, while preserving exact observed output in correction metadata when corrected. Optional provenance task identity must match `input.current_request.observation.task_id`. Persistence is exclusively through the canonical M08-001 creation path.

`RecoveryRecommendation::validate()` is now reusable publicly without changing recovery prompt/schema/parser/bounds or runtime legality behavior.
